# 系统使用手册

**系统名称：** 游戏平台账号租赁智能运营分析系统  
**适用对象：** 运营人员、管理员、演示与验收人员  
**配套文档：** [07-系统架构与技术实现.md](07-系统架构与技术实现.md)

本手册按「日常怎么用」编写。架构、技术栈与实现细节见配套文档。

---

## 1. 系统能做什么

系统面向游戏账号租赁平台运营，把 **看数、问数、问规则、异常归因、策略建议** 放在同一套界面里：

| 能力 | 给谁用 | 说明 |
|------|--------|------|
| 运营驾驶舱 | 运营 | 看 GMV、订单量、出租率、退款率、趋势与游戏排行 |
| 智能问数 | 运营 | 用自然语言查业务库（只读 SQL） |
| 知识问答 | 运营 | 按 SOP / 退款 / 定价 / 风控文档作答，无命中不编造 |
| 异常分析 | 运营 | 对比窗口指标，下钻贡献游戏 |
| 策略建议 | 运营 | 根据指标（可选对照规则）给出建议，**不改业务数据** |
| 智能助手 | 运营 | 自动判断走哪条能力，可排队异步执行 |
| 知识库管理 | 管理员 | 前台上传单篇 Markdown、列表查看切片、删除；也可脚本整目录入库 |

第一阶段策略 **只建议、不落库改价/改订单**。要求改库、删改订单、直接改价等会被拒绝。

## 2. 启动与访问

应用跑在本机；PostgreSQL 本机或已有实例；Milvus / Redis 可用虚拟机 Docker（档 A）。

### 2.1 后端（8888）

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --host 127.0.0.1 --port 8888 --reload
```

检查：浏览器打开 http://127.0.0.1:8888/docs ，或访问 http://127.0.0.1:8888/api/v1/health 。  
期望：`data.status=ok`，且 `data.database.ok=true`。

### 2.2 前端（5173）

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。前端把 `/api` 代理到后端 `:8888`。

### 2.3 首次数据（管理员）

库 `game_ops` 已存在，且根目录 `.env` 中 `DATABASE_URL`、`APP_PORT=8888` 已配置。

```powershell
cd backend
.\.venv\Scripts\python -m scripts.init_db --drop
.\.venv\Scripts\python -m scripts.seed_demo
.\.venv\Scripts\python -m scripts.ingest_knowledge --reset
```

- `init_db`：建表  
- `seed_demo`：模拟 6 款游戏、约 60 天运营数据  
- `ingest_knowledge`：知识库切分 + Embedding + 写入 Milvus / PostgreSQL 切片表  

知识原文目录：`data/knowledge/`（SOP、退款、定价、风控等 Markdown）。

## 3. 登录与角色

打开前端后先登录。Token 保存在浏览器本地，请求头带 `Authorization: Bearer <token>`。

| 账号 | 密码 | 角色 | 权限 |
|------|------|------|------|
| `operator` | `Operator@123` | 运营 | 看板、智能问答、MCP 只读调用 |
| `admin` | `Admin@123` | 管理员 | 以上全部 + 知识入库 |

退出：驾驶舱右上角退出登录。

未登录访问受保护接口返回 401。

---

## 4. 运营驾驶舱

登录后进入驾驶舱，主要区域：

1. **时间范围：** 近 7 / 14 / 30 天。  
2. **指标卡：** GMV、订单量、出租率、退款率、可出租账号、活跃游戏。  
3. **趋势图：** 切换 GMV / 订单量 / 出租率 / 退款率。  
4. **游戏排行：** 同样可切换指标；点击某游戏查看详情。  
5. **智能提问：** 打开问答对话框。

数据来自 PostgreSQL 日指标与订单汇总，不是模型编造。健康状态可在页内或 `/api/v1/health` 查看。

## 5. 智能助手（问答对话框）

打开「智能问答」进入微信式界面：左侧会话列表，右侧当前聊天。  
问数、问规则、异常、策略均由 Supervisor 自动路由。左侧「＋」新建对话，点击切换会话，× 删除；关闭面板后再打开仍保留本次会话列表（刷新页面会清空）。

输入问题后回车或点击发送。回答可展开执行步骤 / SQL / 来源。

### 5.1 推荐问法

**问数**

- 最近 7 天全站 GMV 是多少？  
- 近 14 天出租率最高的游戏有哪些？  
- 最近 30 天退款率是多少？  

**问规则**

- 什么情况下可以全额退款？  
- 账号上架要走哪些步骤？  
- 风控冻结账号的规则是什么？  

**异常**

- 最近出租率为何异常？  
- 最近出租率为何异常？按退款规则该怎么处理？  

**策略（仅建议）**

- 根据最近指标给出运营策略建议  
- 按定价规则给出调价建议  

**会被拒绝的问法**

- 把某游戏价格改成 xxx 并写进数据库  
- 删除订单 / 执行 INSERT、UPDATE、DROP  

### 5.2 智能模式与异步队列

智能模式会：

1. `POST /api/v1/agent/sessions/{id}/ask/async` 入队  
2. 轮询 `GET /api/v1/agent/tasks/{task_id}`  
3. 完成后展示 `result_summary`  

队列：`.env` 中 `REDIS_URL` 为空则用 **进程内队列**；配置 Redis 后走 Redis 列表 `game-ops:agent:jobs`。进程重启会丢失未处理的内存队列任务。

`GET /api/v1/agent/queue/status` 可查看队列后端（memory / redis）是否可用。

### 5.3 问数 / 问规则（流式）

这两种模式走 SSE：`phase` / `meta` / `token` / `done` / `error`。适合边生成边看字。OpenAPI 里仍保留非流式 JSON，便于脚本调试。

## 6. 知识库使用注意

- 回答应能对应到来源切片；前端/接口可能带 `refs`。  
- 检索无结果时会明确说明 **无知识依据**，不要把模型常识当成平台规则。  
- **前台管理（推荐）：** 使用 `admin` 登录驾驶舱 →「知识库管理」→ 选择类型并上传 `.md` → 列表可查看切片、删除。  
- 同名路径再次上传会覆盖旧文档。文件落在 `data/knowledge/uploads/`。  
- 整目录重建：`python -m scripts.ingest_knowledge --reset` 或 `POST /api/v1/knowledge/ingest`（需 admin）。  
- 检索调试：`POST /api/v1/knowledge/search`，可指定 `"mode":"vector"` 或 `"hybrid"`。  

Rerank：`.env` 中 `RAG_RERANK_ENABLED=true` 且配置了 `RERANK_BASE_URL` / `RERANK_API_KEY` / `RERANK_MODEL` 时启用；失败则回退 Hybrid/RRF 排序。

## 8. 可选基础设施（虚拟机 Docker）

应用本身不进容器。虚拟机上：

```bash
cd /path/to/game/docker
docker compose up -d
docker compose ps
```

默认拉起 **Milvus**（`19530`）和 **Redis**（`6379`）。Windows `.env` 示例：

```text
MILVUS_URI=http://<虚拟机IP>:19530
REDIS_URL=redis://<虚拟机IP>:6379/0
```

`MILVUS_URI` 留空则用本机 Milvus Lite。不要在 Windows 上把 `MILVUS_URI` 写成 `http://127.0.0.1:19530`（那是虚拟机端口，本机会误回退 Lite）。

详见 [docker/README.md](../docker/README.md)。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 健康检查 database 失败 | 检查 PostgreSQL 与 `DATABASE_URL`，确认库 `game_ops` 存在 |
| 看板没数 | 执行 `seed_demo`；确认日期范围落在模拟数据窗口 |
| 知识问答无依据 | 先 `ingest_knowledge`；确认 Embedding / Milvus 可连 |
| 智能问答一直排队 | 重启 uvicorn（worker 在进程启动时拉起）；看 `/agent/queue/status` |
| 问数报 SQL 错误 | 换更明确的指标问法；系统只允许 SELECT/WITH，失败会校验并最多再生成一次 |
| 策略回答强调不改数据 | 正常。系统不会自动改价、改库存、改订单 |
| 登录后接口 401 | Token 过期或未带 Authorization；重新登录 |

## 10. 安全与合规（使用侧）

- 不要把账号密码、支付信息贴进问答。  
- AI 路径禁止写业务库。  
- 演示数据为模拟数据，不代表生产真实订单。  
- 策略建议需人工复核后再到业务系统操作。
