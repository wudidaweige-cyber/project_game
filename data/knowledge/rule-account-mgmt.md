# 账号管理规则

**文档类型：** 账号管理规范  
**适用角色：** 账号运营、质检  
**版本：** 模拟 V1.0

---

## 1. 账号生命周期状态

| 状态 | 含义 | 是否可下单 |
|------|------|------------|
| `available` | 可租 | 是 |
| `rented` | 出租中 | 否（已被占用） |
| `offline` | 下架/维护 | 否 |
| `frozen` | 冻结（风控/违规） | 否 |

## 2. 发布与维护规范

1. 上架前必须完成信息完整性检查（游戏、价格、卖点、状态）。
2. 密码与二次验证信息仅存于受控密钥系统，禁止写入运营文档、工单明文、模型提示词。
3. 同一账号同时只允许一笔进行中的租赁订单。
4. 累计投诉达到阈值（模拟：30 天内有效投诉 ≥ 3）必须下架复盘。

## 3. 违规处理

以下行为视为账号侧违规或高风险：

- 账号被用于代练中的作弊工具（若游戏官方通报）
- 账号出现异常异地频繁登录且无法解释
- 供应商提供账号与描述严重不符且拒不整改

处理阶梯：

1. 立即 `frozen`
2. 关联未完成订单按退款规则处理
3. 复盘后决定永久下架或整改后重新上架

## 4. 库存与出租次数

- `rent_count` 用于评估账号热度与损耗。
- 高出租次数账号应提高巡检频率（模拟：每 20 次租赁至少巡检 1 次）。

## 5. 数据安全

- 对外展示仅可使用脱敏账号标识。
- 导出账号列表需管理员权限，并保留审计日志。
